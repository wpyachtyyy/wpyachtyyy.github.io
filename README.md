# Art & Design Portfolio — starter kit

A responsive single-page portfolio for illustration, comics, graphic design and UI/UX. No build tools or coding software are required.

## Before publishing
1. Open `index.html` and replace the sample name/bio/contact details.
2. Add your images in the `images` folder.
3. For each project card, replace the placeholder inside its `.thumb` div with an image tag. Example:
   `<img src="images/project-01.jpg" alt="Description of the artwork">`
4. Update the email link `YOUR_EMAIL@example.com`.
5. Update the footer name if desired.

## Publish on GitHub Pages
1. On GitHub.com, create a **public** repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Open the repository and choose **Add file → Upload files**.
3. Upload `index.html`, `README.md`, and the `images` folder (including any images you add).
4. Click **Commit changes**.
5. Open **Settings → Pages**. Under Build and deployment choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
6. Visit `https://YOUR-USERNAME.github.io`. It may take a few minutes to publish.

## Image tips
- Use JPG for painted artwork and photos; PNG for transparency or crisp graphics.
- Use reasonably sized images (around 1500–2000 px on the long edge; compress large files).
- Use filenames without spaces, e.g. `character-design-01.jpg`.
- Only upload artwork you have permission to publish. Your repository's files are public when the repository is public.
